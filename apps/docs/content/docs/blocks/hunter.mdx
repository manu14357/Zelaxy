# Hunter io Block

The Hunter io block lets you find and verify professional email addresses using Hunter.io. Reach for it when you need to discover contacts at a company, build a verified email address from a name and domain, check deliverability, or enrich your prospecting data.

## Overview

| Property | Value |
|----------|-------|
| **Type** | `hunter` |
| **Category** | tools |
| **Color** | `#E0E0E0` |

## When to Use

- Pull all known email addresses for a company domain (domain search) for lead generation.
- Build a likely email address for a specific person from their first name, last name, and domain (email finder).
- Verify whether an email address is deliverable before sending (email verifier).
- Discover companies that match a free-text search query (e.g. "software companies in San Francisco").
- Look up details for a single company by its domain (find company).
- Count how many personal vs. generic emails exist for a domain before committing to a full search (email count).

## Configuration

### Operation

A dropdown that selects which Hunter.io action to run: Domain Search, Email Finder, Email Verifier, Discover Companies, Find Company, or Email Count. The remaining fields shown depend on this choice.

### Domain

The company domain to operate on (e.g. `stripe.com`). Required for domain search, email finder, find company, and email count.

### First Name / Last Name / Company Name

Used by Email Finder to construct a person's email address. First and last name are required; company name is optional.

### Email Address

The email to check for deliverability when using Email Verifier.

### Search Query

The free-text query used by Discover Companies to find matching organizations.

### Result Filters

Optional refinements for domain search and email count: number of results (limit), email type (all / personal / generic), seniority level, and department.

### API Key

Your Hunter.io API key. Required and stored as a password field.

## Inputs & Outputs

- **Inputs**: `operation` (string), `apiKey` (string), `domain` (string), `limit` (number), `offset` (number), `type` (string), `seniority` (string), `department` (string), `first_name` (string), `last_name` (string), `company` (string), `email` (string), `query` (string), `headcount` (string), `company_type` (string), `technology` (string)
- **Outputs**: `results` (json), `emails` (json), `email` (string), `score` (number), `result` (string), `status` (string), `total` (number), `personal_emails` (number), `generic_emails` (number)

## YAML Example

```yaml
hunter_1:
  type: hunter
  name: "Hunter io"
  inputs:
    operation: "hunter_domain_search"
    domain: "stripe.com"
    limit: 10
    type: "all"
    apiKey: "{{HUNTER_API_KEY}}"
  connections:
    outgoing:
      - target: next-block-id
```
