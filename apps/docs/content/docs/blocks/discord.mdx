# Discord Block

The Discord block connects your workflow to Discord, letting you send messages, read channel history, and look up server and user information. Reach for it to automate notifications, community management, and Discord-driven integrations.

## Overview

| Property | Value |
|----------|-------|
| **Type** | `discord` |
| **Category** | tools |
| **Color** | `#E0E0E0` |

## When to Use

- Post automated notifications or alerts into a Discord channel.
- Send dynamic, workflow-generated messages to a community server.
- Pull recent channel messages to feed downstream steps (e.g., summarization or moderation).
- Fetch server information for onboarding or reporting flows.
- Look up a specific user's information by ID.

## Configuration

### Operation
Choose what the block does: Send Message, Get Channel Messages, Get Server Information, or Get User Information. Defaults to Send Message.

### Bot Token
The Discord bot token used to authenticate requests. Required for every operation.

### Server
Select a Discord server (basic mode) or enter a server ID manually (advanced mode). Required for sending messages, getting messages, and getting server info.

### Channel
Select a Discord channel (basic mode) or enter a channel ID manually (advanced mode). Required for sending and getting messages.

### User ID
The Discord user ID to look up. Used by the Get User Information operation.

### Message Content
The text to post. Used by the Send Message operation.

### Message Limit
Number of messages to retrieve (default 10, max 100). Used by the Get Channel Messages operation.

## Inputs & Outputs

- **Inputs**: `operation` (string), `botToken` (string), `serverId` (string), `manualServerId` (string), `channelId` (string), `manualChannelId` (string), `content` (string), `limit` (number), `userId` (string)
- **Outputs**: `message` (string), `data` (json)

## YAML Example

```yaml
discord_1:
  type: discord
  name: "Discord"
  inputs:
    operation: "discord_send_message"
    botToken: "{{secrets.DISCORD_BOT_TOKEN}}"
    serverId: "123456789012345678"
    channelId: "234567890123456789"
    content: "{{start.input}}"
  connections:
    outgoing:
      - target: next-block-id
```
