# Jira Block

The Jira block connects to Jira workspaces to read, write, and update issues. Reach for it when your workflow needs to pull issue content and metadata, create new issues, or keep Jira up to date as part of an automation.

## Overview

| Property | Value |
|----------|-------|
| **Type** | `jira` |
| **Category** | tools |
| **Color** | `#E0E0E0` |

## When to Use

- Read a single Jira issue's summary, description, and timestamps into your workflow.
- Bulk-read all issues from a Jira project for reporting or triage.
- Create a new Jira issue (write) from upstream workflow data.
- Update an existing issue's summary and description automatically.
- Integrate Jira documentation and issue metadata into AI-driven workflows.

## Configuration

### Operation

Dropdown selecting the action to perform: Read Issue (`read`), Read Issues (`read-bulk`), Update Issue (`update`), or Write Issue (`write`). Defaults to `read`.

### Domain

The Jira domain to connect to, e.g. `zelaxy.atlassian.net`. Required.

### Jira Account

OAuth credential for authenticating against Jira. Required.

### Select Project / Project ID

Pick a project with the project selector (basic mode) or enter a project ID manually (advanced mode). Required for write and read-bulk operations.

### Select Issue / Issue Key

Pick an issue with the file selector (basic mode) or enter an issue key manually (advanced mode). Shown for read and update operations.

### New Summary / New Description

The summary (required) and description to set when writing or updating an issue.

## Inputs & Outputs

- **Inputs**: `operation` (string), `domain` (string), `credential` (string), `issueKey` (string), `projectId` (string), `manualProjectId` (string), `manualIssueKey` (string), `summary` (string), `description` (string), `issueType` (string)
- **Outputs**: `ts` (string), `issueKey` (string), `summary` (string), `description` (string), `created` (string), `updated` (string), `success` (boolean), `url` (string)

## YAML Example

```yaml
jira_1:
  type: jira
  name: "Jira"
  inputs:
    operation: "read"
    domain: "zelaxy.atlassian.net"
    credential: "{{credentials.jira}}"
    issueKey: "PROJ-123"
  connections:
    outgoing:
      - target: next-block-id
```
